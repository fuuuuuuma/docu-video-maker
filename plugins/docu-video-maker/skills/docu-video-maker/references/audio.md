# 声・BGM・効果音

## 声

- ElevenLabs：鍵は環境変数 `ELEVENLABS_API_KEY` か `~/.config/elevenlabs/api_key`（権限600）。鍵の値を会話・ファイル・コミットに出さない
- 候補を出す：`python3 el.py voices --search japanese`（ライブラリの声は、作り手のアカウントの「My Voices」に加えると ID で使える）
- **声は作り手に選んでもらう**。同じ1文を3声で読ませたファイルを渡す：
  `python3 el.py tts --text "マリー・アントワネットには、四人の子どもがいました。" --voice <ID> --model eleven_v3 --lang ja --out try_<名前>.mp3`
- 同じ声の調子を保つため `seed` を固定する（既定1789）
- 読み違える固有名詞は、その行に `"tts": "読み"` を書く。書き直したら `audio/lines/<行ID>.mp3` を消して `audio.py tts` を流し直す
- 無料：macOS の `say`（`say -v '?' | grep ja_JP` で声の一覧。Kyoko・Otoya など）。品質は ElevenLabs より落ちることを作り手に伝える

## BGM

- ElevenLabs Music で、扉の位置（題字・章・まとめ・締め）に合わせて曲調を変えた1曲を作る。1曲は最長10分なので、長い回は扉の位置で何曲かに分けて作り、つなぐ（つなぎ目は扉の効果音で隠れる）
- 曲調は `bgm.styles` で差し替えられる（既定は歴史ドキュメンタリーの管弦楽）
- 歌詞入り・ポップ・強いドラムは外す
- 手持ちの曲を使うなら `"bgm": {"file": "曲のパス"}`（商用利用できる曲だけ）

## 効果音

`python3 audio.py sfx` で14種（衝撃音・whoosh・riser・鐘・紙・時計・心音・羽ペン・馬車・群衆・扉・風など）を一度だけ作り、回をまたいで使う。行ごとに `"sfx": [{"name": "door_slam", "t": 0.4}]` で足せる。

### ElevenLabs の鍵が無いとき（無料の効果音を取り込む）

作り手に下の表の言葉で探して取ってきてもらい、`<名前>.mp3`（wav・m4a なども可）に名前を付けて 1 つのフォルダに集めてもらう。

```bash
python3 audio.py sfx --from <フォルダ>     # 既にある名前は飛ばす。入れ替えるなら --force
```

頭の無音を詰め、決まった秒までに切り、ピークを -3dB にそろえて `~/.cache/docu-video-maker/sfx/` に入れる。表に無い名前（`rain` など）もそのまま取り込めて、行の `sfx` から同じ名前で呼べる（長さは10秒まで）。足りない名前は最後に出る。

| 名前 | 秒 | 効果音ラボで探す言葉 | Mixkit で探す言葉 |

| impact_soft | 3 | 重低音・ドン | deep boom |
| whoosh | 1 | シュッ・風切り | whoosh |
| riser | 4 | 緊張・せり上がる | riser |
| glitch | 1 | ノイズ・グリッチ | glitch |
| bell_toll | 5 | 教会の鐘 | church bell |
| paper_flip | 1 | 紙をめくる | page turn |
| tick | 2 | 時計の秒針 | clock ticking |
| heartbeat | 3 | 心臓の鼓動 | heartbeat |

| 場所 | 動画での利用 | してはいけないこと |
|---|---|---|
| [効果音ラボ](https://soundeffect-lab.info/) | 商用・収益化した YouTube も可、クレジット不要 | 音のファイルの再配布（効果音を組み込んだテンプレート・素材集・アプリも再配布あつかい）、効果音だけを流す動画、AI 学習、Content ID などへの登録、アダルト・公序良俗に反する作品 |
| [Mixkit](https://mixkit.co/free-sound-effects/) | 商用可、クレジット不要 | 音のファイルそのものの配布・販売（素材集にしない） |

- 取るのは作り手自身（サイトの規約に同意して手で取る）。エージェントは探す言葉を出し、取ってきたファイルを使う
- スキル・prproj・テンプレートなど**配る物には同梱しない**
- 規約は変わるので、使う前に上のリンクで確かめる（2026-10-25 に確認）

どちらも無ければ効果音なしで組み立てる。

## 演出の音（静かな間・音の受け渡し）

- 静かな間：行に `"hush": 秒` を書くと、その行の前にその秒だけ間が空き、BGM もほぼ消える（-36dB まで 0.4 秒で下げ、声と一緒に 0.6 秒で戻す）。絵は前のカットが残る。書き出しとプレビューの両方で効く。山場や転機の前に 1〜1.5 秒を 2 か所以上
- 音の受け渡し：`sfx` の `t` は行の始まりからの秒で、負にもできる。`"t": -0.6` なら場面が変わる少し前から次の場面の音が鳴る
- 見える動きには音：扉・馬車・紙・時計・群衆・風は 14 種の効果音にある

なぜそうするかは [directing.md](directing.md)。

## ミックス

声に軽い残響、声のある所で BGM を下げ、2段の loudnorm で -14 LUFS・ピーク -1.5dB。書き出しの直後に音の有無を検査し、音が無ければ止まる（昔、版名の食い違いで無音の書き出しが出たことがある）。
