# 叩き台と質問

作り手は「参考の URL を渡せば、いい感じに作ってくれる」ことを期待している。最初から10問並べると、考える負担を作り手に返すことになる。参考を読んで案を持ってきてから、決めないと作れないことだけを聞く。

## 叩き台（質問の前に出す）

1画面に収まる量で、次の形で出す。

```
■ 参考から読み取ったこと（3〜5行）
- 例：題名は「人物名＋その後＋余韻」の型。20分前後。カットは約7秒で切り替わる。下に要約字幕、要所に赤い強調
- サムネは〇〇の型（顔の寄り／絵を全面に敷いて問いを載せる…）

■ コンセプト（チャンネルなら）
- 名前の案と軸を一言で。参考と食い合わない切り口にする（例：日本史の「その後」に対して、世界史の「その後」）

■ 題材の候補
1. 〇〇（推奨）— 選んだ理由：検索される人物・史料が足りる・意外な結末がある
2. △△
3. □□

■ 構成案（推奨の題材）
ダイジェスト（山場を30秒で先に見せる）→ 題字 → 第1章 … → まとめ（一言でいえば〜）
形は 一本の旅／前と後／数え下げ のうち〇〇（理由を1行）。冒頭の画は〇〇、締めは冒頭の〇〇に戻る

■ 手本（この回のために選ぶ）
- 〇〇（映画・番組・予告）— 学ぶ所：間合い・カメラ・色 ／ 取らない所：人物・決めの画・曲

■ 見た目
- 上下の黒帯、下の帯に要約1行の通常テロップ、山場にだけ演出テロップ（左上・中央・右下・縦書きを順に）
- 絵はカットごとに別。名画〇割・AI 画像〇割・AI 動画は約6カットに1本・地図は移動の場面
- 参考から変える点：（同じ型の量産に見えないように、構図・色・題名の型のどれかを変える）
```

## 質問（叩き台の直後に、4問前後）

選択肢を付け、推奨を先頭に置く。作り手が答えやすいように1問1行で。

| 問い | 選択肢（推奨を先に） | 答えで決まる設定 |
|---|---|---|
| 長さ | 20分前後／10分前後／3分の PV | 行数と章の数、`cards`、`pace`（下の表） |
| 題材と構成 | 推奨のまま／変えたい章を言う | 台本 |
| 使える有料サービス | ElevenLabs と Higgsfield／ElevenLabs だけ／どちらも無し | `voice.provider`、`bgm`、AI 素材を作るか |
| Higgsfield の上限 | 200／500／1,000 クレジット | `new_assets.json` の枚数 |
| 声 | 試し読み3声から選ぶ | `voice.id` |

声は文字で選べないので、同じ1文を3声で読ませた音声ファイルを渡して選んでもらう（ElevenLabs は `python3 el.py voices --search japanese` で候補を出す。無料なら macOS の `say -v '?'` の日本語の声）。

テロップの色や置き方、カットの速さは聞かない。既定の型で作って見せ、直したい所を言ってもらうほうが早い。

## 長さ別の設定

| 長さ | 行数の目安（1行≒6秒） | 章 | `cards` | `pace` | 素材の目安 |
|---|---|---|---|---|---|
| 3分の PV | 25〜35行 | なし（ダイジェストと本編とまとめ） | `{"title": true, "chapters": false, "end": true}` | `"fast"` | 絵40点前後 |
| 10分前後 | 90〜110行 | 3〜4章 | 既定 | `"normal"` | 絵150点前後 |
| 20分前後 | 190〜220行 | 5〜6章 | 既定 | `"normal"` | 絵370点前後（名画100〜150＋AI 画像200前後＋AI 動画40前後） |

## 有料サービスの組み合わせ

| 使えるもの | 声 | BGM | 効果音 | 絵 |
|---|---|---|---|---|
| ElevenLabs と Higgsfield | ElevenLabs | ElevenLabs で章に合わせて作曲 | ElevenLabs で14種 | 名画＋AI 画像＋AI 動画＋地図 |
| ElevenLabs だけ | ElevenLabs | 作曲 | 14種 | 名画＋地図（同じ絵を続けないよう名画を多めに集める） |
| どちらも無し | macOS の `say`（品質は落ちると伝える） | 手持ちの曲（`"bgm": {"file": "..."}`）か無し | 無し | 名画＋地図 |

費用の目安（2026年10月時点の実測）：Higgsfield は GPT Image 2.5 中画質 2k が1枚1.0、Kling 3.0 pro 5秒が1本7.5。20分の回で画像約200枚＋動画約40本＝約500クレジット。ElevenLabs は20分の読み上げで約1.5万文字。
