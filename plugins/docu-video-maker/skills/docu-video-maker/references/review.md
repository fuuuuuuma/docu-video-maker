# 審査（作っていない目で採点して直す）

自分で作った動画は甘く見える。書き出したら、作っていない担当に厳しく採点させ、その指摘で直し、もう一度採点させる。台本の段のファクトチェックとは別で、こちらは映像としての出来を見る。

## いつ・誰が

- `qa.py` の「直すこと」が「なし」になってから、作り手に見せる前
- 審査役は新しく立てた別の担当。Claude Code はサブエージェント（Agent ツール）、Codex は別のエージェントか新しい会話。前の版の審査役を使い回さない（自分の指摘に甘くなる）
- 渡すのは「動画のパス」「仕様（`script.json`・長さ・作風・参考から変える点）」「`look.py` の場所」「`qa/` の一覧」だけ。作った側の苦労や意図は書かない（引きずられる）
- 審査役はファイルを読むだけで、直さない

## 頼み方（そのまま使える）

```
あなたは映像の審査員です。この動画は作っていません。一流の水準に届かせるために、遠慮なく、具体的に審査してください。褒め言葉は要りません。

対象: <回>/exports/<slug>_<版>.mp4
仕様: <回>/script.json（台本・題字・作風）、長さ <分>、1920×1080・上下に黒帯のドキュメンタリー風、<参考から変える点>
見る道具: python3 <スキル>/scripts/look.py（cuts / fast / strip / crop / read）。<回>/qa/ に一覧が出ている

1. 見る（数字だけで決めない）
   - qa/cuts_*.jpg：全カットの頭・中・終わり。qa/sheet_*.jpg：6 秒ごとの流れ。qa/fast_*.jpg：動きの速い所の全コマ
   - 見せ場（演出テロップ・扉・赤い語の瞬間）の前後は look.py strip で全コマ、顔・手・文字の縁は look.py crop で原寸
2. 仕様を確かめる：長さ、音がある、-14 LUFS 前後、意図しない黒や止まった区間が無い、赤い語の衝撃音と画面の乱れが合っている
3. 7 つの観点を 1〜10 点で採点する。5＝学生の課題、6＝テンプレート並み、7＝しっかりした仕事、8＝一流の制作会社、9＝賞の候補、10＝世界一。最初の書き出しは 5〜7 が普通。甘くしない
   - 語りと絵：語っている中身と絵が合う、時代違いが無い、同じ絵が続かない
   - 引き：冒頭 3 秒で続きを見たくなる、山場がはっきりある、締めが冒頭と響き合う
   - 動き：寄り・パン・溶けの速さと止め、急なカメラが無い、動かない区間が長すぎない
   - 文字と構図：通常テロップ・演出テロップ・年号・扉の読みやすさ、置き場所、余白、日本語の組み方
   - 仕上げ：色・粒子・ギザギザ・縞・切り抜きの縁・帯の段差
   - 音：声・BGM・効果音の釣り合い、静かな間、音の受け渡し、山場と音の一致
   - 技術：仕様どおり、書体の欠け（□）が無い、ちらつき・音の割れが無い
4. 直すことを 5〜10 件、効きの大きい順に。各件に「時刻／見えていること／なぜ効くか／どう直すか（行 ID・秒・カット番号・dB・px など数字で）」。細かい指摘を並べるより、大きな改善を少し。少なくとも 1 件は驚き・見せ場を上げる直しにする
5. 致命は別に挙げる：テンプレートや AI の定型に見える所、不自然な日本語、代わりの書体・□、仕様違反、生々しい描写、実在の現代人物の顔
6. 耳でしか分からない所（声の聞こえ方・間合いの気持ちよさ）は「未確認」と書く

返すもの：点数表・致命の一覧・直すことの一覧
```

## 直す（作った担当）

- 今の版を残す。直した版は次の版名（v1 → v2）で書き出す。上書きしない
- 致命と、効きの大きい直しは全部入れる。もっと良い直し方に自信があれば替えてよい（理由を書く）。審査役が良いと言った所は崩さない
- 書き出し直したら `qa.py` を流し、直した所を `look.py strip` / `crop` で見て、本当に直ったか確かめる
- 点数表と、採った直し・見送った直しと理由を `qa/review_<版>.md` に残す

## 何周回すか

- 目標：全観点 8 点以上・致命 0。審査と直しは 3 周まで（それ以上は時間と費用が見合わない）
- 届かなかった観点は、点数と理由をそのまま作り手への報告に書く。上がったふりをしない
- 有料の生成（AI 画像・動画の作り直し）が要る直しは、見込みを出して作り手の承認を取ってから
