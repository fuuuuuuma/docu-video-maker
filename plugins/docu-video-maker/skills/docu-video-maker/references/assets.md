# 素材の集め方と作り方

## 名画・版画（ウィキメディア・コモンズ）

```bash
python3 commons_fetch.py search "Marie Antoinette children Vigee Le Brun"   # 候補（○だけ使える）
python3 commons_fetch.py get <回> px_family "File:xxxx.jpg" "王妃と子どもたち（1787）"
```

- 使うのは **PD（パブリックドメイン）と CC0 だけ**。CC BY 系や不明なものは取らない（クレジットの書き方を誤ると規約違反になる）
- 検索語は英語や原語（仏語・独語）のほうが当たる。カテゴリ名（`Category:...`）で探すと同じ人物の絵がまとまって出る
- 短辺900px以上を選ぶ（小さい絵は画面で粗く見える）
- 外すもの：血や遺体の描写、遺骸・心臓などの実物写真、文字だけのページ、人物の比定が不確かな絵
- **後年に描かれた歴史画**（例：1850年の絵で1795年の場面）は、当時の絵として扱わない。雰囲気づけに使うなら作り手に伝える
- メダル・地図・風刺版画は「肖像」としては使わない
- 出典は `sources.json` に自動で残る（概要欄と固定コメントのクレジットに使う）

## AI 画像・動画（Higgsfield）

```bash
higgsfield auth login                 # 作り手が対話で（エージェントからはできない）
python3 gen_assets.py <回> --dry      # 枚数と見込みクレジット
python3 gen_assets.py <回> --workers 8
```

- 画像は GPT Image 2.5 中画質 2k 16:9（1枚1.0）、動画は Kling 3.0 pro 5秒（1本7.5）。動画の元の画像は、静止画としては使わない（同じ絵が2度出る）
- **生成の前に、枚数と見込みクレジットを作り手に示して上限の承認を取る**。途中で上限を超えそうなら止める
- Homebrew の `hf` は Hugging Face の別物。Higgsfield は `higgsfield` コマンド
- 同時に投げすぎると混み合いで失敗する。失敗は自動で4回まで待って再試行し、記録は `gen_log.jsonl`

### プロンプトの決まり

- 画調は `image_style` が自動で足されるので、prompt には場面だけを書く
- 動画の prompt は動きだけを書く。カメラの動き・照明・構図は名前で 1 つずつ（例 `slow dolly in`・`low-key lighting`）。名前の探し方は [directing.md](directing.md) の「手本と言葉の探し方」
- 文字・看板・手紙の読める文字は描かせない（崩れた文字が出る）
- 処刑・遺体・血は描かせない。死は空の寝台・消えたろうそく・閉じた扉などの象徴で
- 人物の年齢を語りの時点に合わせて書く（例：1795年の16歳の王女）
- 同じ人物は `ref` に肖像を入れて顔や服をそろえる

### 生成後に必ず見る（一覧にして全部）

今回の制作で実際に出た失敗。生成した画像は縮小を並べた一覧を作り、1枚ずつ確かめる。

- **時代違いの物**：1800年代前半の街にエッフェル塔（1889年）が描かれていた
- **現代の場面の時代衣装**：画調の文（18世紀の歴史画）に引っ張られ、1998〜2014年の DNA 鑑定の研究室に、かつら姿の人物が描かれた → `"era": "modern"` を付けて作り直す
- **実在の現代人物**：存命・近年の実在人物（王族の子孫など）の顔を AI で描かない。写真立て・試料・紋章など物で見せる
- **生々しい描写**：一覧では遺体に見えるもの（墓の大理石像など）は原寸で確かめる
- 縦長で出た動画（縦長の絵を元にしたとき）は、組み立てでぼかした地に置かれる

## 地図

```bash
python3 fetch_map_data.py    # 初回だけ（約2.4MB）
```

`scenes` に `kind: "map"` で書く（形式は script-format.md）。地名は日本語で、`at` で出る秒、`routes` で赤い線が伸びる。

## カット表を作る

`shots.py <回>` を一度流すと `shots_plan.json`（カットの順番）ができる。`python3 make_cuts.py <回>` で、各カットの番号・秒・読まれる文・いまの場面と、手持ち素材の一覧（`cuts.json`・`inventory.json`）が出る。これを元に `shotlist.json` と `new_assets.json` を作る（条件は script-format.md）。
