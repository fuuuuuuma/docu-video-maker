# 公開用の一式

作るのはファイルと文章まで。YouTube への登録・アップロード・投稿は作り手が手動で行う。

## タイトル

- 5案と推奨1つ。冒頭の約25字に検索される語（人物名・出来事）を入れる
- 型の例：「〇〇のその後…〜」（人物名＋その後＋余韻）、「なぜ〇〇は〜のか」（問い）、数字（「4人中ひとり」）
- 動画の中身より強く言わない（「真実」「証明」「確定」「生きていた」などは、中身が言い切っていなければ使わない）
- サムネの文言と同じことを言わない（タイトルとサムネで別の切り口にすると、クリックの理由が増える）

## サムネイル（1280×720）

`make_thumbnail.py <設計.json> <出力.png>`：絵を1枚全面に敷き、反対側に太い明朝の問いを、大きい漢字と小さいかなの階段で組み、1語だけ赤くする型。設計の書き方はスクリプトの先頭（JSON にコメントは書かない）。

- 2〜3案作り、YouTube Studio の「テストと比較」で比べることを勧める
- 縮小（320×180）の確認画像も必ず見る。スマホの一覧はこの大きさ
- 文言は事実どおりに（例：「生き残ったのは1人」は、革命前に病死した子がいるなら「大人になれたのは1人」）
- 句読点を入れない。文字は2段まで、汚し（かすれ）は控えめに
- AI で人物の顔の寄りを作る場合は、名画の肖像を `ref` に入れて似せ、過度に悲惨な表情は避ける

## 概要欄（5,000字まで）

```
（2〜3行の要約：何が分かる動画か）

▼チャプター
0:00 オープニング
0:35 第1章 …        ← timeline.json の扉の start を分:秒に

▼主な参考資料
・一次資料・論文・公的機関の発表（URL）

▼映像について
・肖像画・版画・絵画は、ウィキメディア・コモンズで公開されているパブリックドメインまたは CC0 の作品です。作品ごとの作者と所蔵先は、固定コメントに載せています。
・一部の場面は AI で作成したイメージ図で、実際の場面や人物を写したものではありません。
・ナレーションは合成音声です。

#ハッシュタグ（3〜5個）
```

作品ごとのクレジットは概要欄に収まらない（20分の回で100点超）。`sources.json` から「題材（年）／作者（ライセンス）」の1行ずつにして固定コメント（10,000字まで）に入れる。URL 付きの一覧は手元に控えとして残す。

投稿時の設定：「改変または合成されたコンテンツ」は「はい」（AI のイメージ図と合成音声）。カテゴリは教育。

## チャンネルを新しく作る場合

- 名前：コンセプトを言い切る短い名前。YouTube で同名・紛らわしい名前が無いか検索する
- アイコン（800×800）：丸く切り抜かれ、40px でも読める図案。文字は2〜5字
- 説明欄（1,000字まで）：何が見られるチャンネルかを最初の一文で言い切る → こんな方に → 動画について（長さ・諸説の扱い・素材の出典・AI と合成音声の開示）
- 誇張しない（「本当の結末」→「史料から分かる結末」、「教科書が一言で終わらせた」→「一言で語られがちな」）
- 姉妹チャンネルなどの案内は、相手の了承を取ってから載せる

## 外に出す前に

タイトル・概要欄・説明欄・サムネの文言は、ファクトチェックと誇張の検出を通す（サブエージェントが使えるなら別の担当に）。年齢・年・人数・論文の誌名と年を確かめる。
